# 移动端内容布局优化设计

## 目标

根据移动端截图，优化现有工作台在 390px 左右视口下的内容布局：移动导航抽屉不超过视口一半，顶部色彩层次更柔和，工作记录/工作计划/事件提醒不再依赖横向滚动，快捷导航改单列，记账页的分段控件保持文字垂直居中。

## 设计决策

1. 桌面端保留现有 Element Plus 表格与四列快捷导航，不改变接口、数据字段和操作入口。
2. 工作记录、工作计划、事件提醒在移动端提供独立的卡片列表，只呈现移动端最有用字段；桌面表格在移动端隐藏，避免用 `min-width` 换取横向滚动。
3. 移动抽屉宽度使用 `min(300px, 50vw)`，严格不超过视口宽度的一半；现有遮罩、Esc、焦点陷阱和路由关闭行为继续保留。
4. 顶部使用现有主题变量组合渐变色，不新增品牌颜色体系；深色主题同步提供对应色阶。
5. 快捷导航分类允许换行并占满内容宽度，导航卡片在移动端单列，卡片内部使用 `min-width: 0` 和文本截断防止撑宽。
6. 记账页支出/进账与日/月/年控件统一使用可伸缩的分段按钮和 `align-items: center`，确保文字在视觉上垂直居中。

## 验收标准

- 390px 视口下移动抽屉宽度不大于 195px。
- 工作记录、工作计划、事件提醒、快捷导航和记账页 `scrollWidth === clientWidth`，不产生页面级横向滚动。
- 三个列表页的移动卡片仍可完成编辑、删除、关闭/启用等原有操作。
- 桌面端仍显示原表格和原有四列快捷导航。
- 现有前端测试、生产构建和新增移动布局契约测试通过。
