# 移动端弹窗与记账列表优化设计

## 目标

让新增/编辑类弹窗在手机上垂直居中，并消除记账页“分类统计”和“账目明细”两个列表的横向滚动。

## 设计决策

1. 在现有移动端 CSS 中统一覆盖 Element Plus `.el-overlay-dialog`，使用 Flex 居中；弹窗限制最大高度，内容区独立纵向滚动，保证标题和底部操作可见。该规则覆盖工作记录、工作计划、事件提醒、Todo、快捷导航和管理记账分类等现有弹窗。
2. 桌面端继续显示记账页原有两个 `el-table`，移动端隐藏它们并新增对应卡片列表：分类统计卡片显示分类、类型、金额、笔数；账目明细卡片显示日期、类型、分类、备注、金额和删除操作。
3. 移动端卡片使用现有主题变量、状态色和面板圆角，不改变 API、数据模型或操作方法。

## 验收标准

- 390px 移动视口下所有目标弹窗的外层可见区域垂直居中，内容过长时不超出视口。
- 390px 移动视口下记账两个列表不显示横向滚动条，页面和两个卡片列表的可见宽度不超出内容区。
- 桌面端两个记账表格仍可见，移动卡片默认隐藏。
- 记账明细卡片仍可删除记录；分类统计信息完整保留。
- 前端测试、构建和浏览器检查通过。
