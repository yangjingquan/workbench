# 移动端适配设计

## 目标

让 Dev Workbench 在 390px 等手机宽度下具备可用的导航、内容浏览和表单操作体验，同时保持桌面端现有视觉语言、路由和业务行为不变。

## 现状与证据

- `frontend/src/styles.css` 已有 `760px` 断点，但移动端仍保留 72px 图标侧栏，实际内容宽度被持续占用。
- `.page-heading`、`.toolbar`、`.setting-row` 和部分 Element Plus 控件缺少统一的窄屏换行策略。
- `.todo-board`、`.grid-2`、`.tool-grid` 已在手机端改为单列；`.link-grid` 为两列；统计卡在 760px 以下仍为两列，这些行为保留并做间距优化。
- `el-table` 的内容依赖桌面列宽，移动端需要显式设置容器横向滚动，避免页面整体被撑宽。
- 390px 登录页截图未发现明显横向溢出；登录后的真实数据页因本地后端未启动，无法完成真实数据截图，后续以构建、静态结构和可用的本地预览检查为主。

## 设计方案

### 1. 移动端导航

桌面端继续使用现有固定侧栏。`760px` 以下隐藏侧栏，顶部左侧显示菜单按钮；按钮打开一个从左侧进入的移动端导航面板，复用现有 `mainNav` 和工具导航，不新增路由。

移动面板包含品牌、全部导航、设置入口和关闭按钮。点击任意导航项后关闭面板；点击遮罩或关闭按钮也关闭面板。桌面端不渲染移动面板的可见状态，也不改变 `app.collapsed` 的持久化含义。

### 2. 全局内容布局

- 手机顶部栏高度保持触控友好，标题区域允许收缩，右侧保留搜索、主题、账号操作。
- 内容区在手机使用 16px 左右内边距，页面标题和操作区垂直堆叠，主标题字号下调但不改变字重和品牌色。
- `.page-actions`、`.toolbar-left`、`.toolbar-right` 支持换行；按钮在必要时占满可用宽度，避免按钮文本被压缩。
- 面板、表单卡片和弹窗统一使用更小的内边距；表单两列在手机变为单列。

### 3. 页面级响应式行为

- 看板：统计卡保留两列；图表和最近记录单列；图表高度下调以减少首屏滚动成本。
- 记录、计划、提醒、记账明细：表格区域设置 `overflow-x: auto`，保持列内容完整；筛选器和视图切换控件换行。
- Todo：保持三列转单列；卡片底部操作允许换行，拖拽行为不做新的移动端替代。
- 快捷导航：保留两列卡片；卡片操作按钮保持可点击尺寸。
- 工具箱：工具盒单列；按钮组允许换行；时间戳字段单列。
- 记账、备忘录、个人中心、设置：现有双列区域和危险操作区转为单列，设置行改为上下结构，控件使用接近满宽布局。
- 对话框：手机宽度下使用 `calc(100vw - 32px)`，最大宽度仍由桌面端配置控制；底部操作允许换行或横向排列，表单内容不超出视口。

### 4. 可访问性与交互约束

- 菜单按钮提供中文 `aria-label`，移动导航面板具备可见关闭按钮。
- 触控目标保持至少约 40px 高度；不通过缩小文字来解决空间问题。
- 不依赖 hover 才能发现核心操作；现有按钮和链接语义保持不变。
- 桌面端键盘焦点样式和主题色变量继续复用现有定义。

## 变更范围

- 修改 `frontend/src/layouts/AppLayout.vue`：增加移动菜单状态、菜单按钮、移动导航面板和路由切换后的关闭逻辑。
- 修改 `frontend/src/styles.css`：集中补齐移动断点规则，并为表格、弹窗、标题、工具条、设置项和页面特有布局提供窄屏样式。
- 不新增依赖、不改变 API、不改变业务数据结构、不新增页面路由。

## 验收标准

1. 390px 宽度下主布局不出现页面级横向滚动；内容只允许在表格容器内部横向滚动。
2. 手机端可以从顶部菜单打开全部现有导航，并能通过导航、遮罩和关闭按钮退出菜单。
3. 看板、记录、计划、Todo、提醒、快捷导航、工具箱、记账、备忘录、个人中心和设置页面的标题、按钮、表单和主要内容均不被裁切。
4. 760px 以上桌面布局与本次修改前的侧栏、顶部栏和主要网格结构保持一致。
5. `npm run build` 成功；现有前端单元测试继续通过。
6. 在可用的本地预览中检查 390px 和 768px 两个宽度；若后端不可用，记录为验证限制，不伪造登录后数据截图。

## 验证策略

- 先为移动导航状态和响应式关键类补最小化测试或静态断言，再实现代码，遵循当前项目不引入新测试框架的约束。
- 每轮修改后运行前端构建和现有测试。
- 使用本地预览分别检查登录页、移动导航打开/关闭、看板首屏、表格容器、Todo 单列、工具箱单列和设置项堆叠。
