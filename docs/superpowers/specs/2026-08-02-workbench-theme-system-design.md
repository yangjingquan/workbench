# Workbench 多色系主题设计

## 背景与目标

Workbench 当前使用蓝紫色视觉体系。为了让界面更爽朗、大气、简洁，同时保留现有品牌识别，需要把颜色从单一变量扩展为可切换的主题色系：

- 蓝紫品牌主题：保留当前 Workbench 的品牌感，作为默认主题。
- 天蓝青绿主题：使用明快的天蓝与青绿色，作为更轻盈、清爽的备选主题。

两套主题必须共享现有页面结构、功能、路由、接口和组件布局。用户切换主题后，登录页、登录成功后的所有页面、图表和 Element Plus 控件都应同步变化；刷新页面后仍保留上次选择。

## 设计方向

### 1. 页面基底

- 浅色模式使用略带冷色的浅灰蓝背景，内容区保持大面积留白。
- 面板、表格和表单使用纯白表面，以轻边框和低强度阴影建立层级。
- 侧栏保留深色高对比区域，但根据主题切换为蓝紫或深海蓝版本。
- 圆角、间距、字号和信息架构保持现有产品节奏，不通过增加装饰性卡片填充空间。

### 2. 主题色系

颜色通过 CSS 自定义属性集中定义，页面和组件只消费语义变量，不在页面中直接写主题色。

| 语义变量 | 蓝紫品牌主题 | 天蓝青绿主题 | 使用范围 |
| --- | --- | --- | --- |
| `--primary` | `#5B5CE2` | `#159FD0` | 主按钮、链接、选中态、图表主色 |
| `--primary-strong` | `#4546C6` | `#0E7EA8` | 悬停态、侧栏强调态 |
| `--primary-soft` | `#EEF0FF` | `#E7F8FC` | 浅色背景、选中行、柔和标签 |
| `--accent` | `#8A7DFF` | `#18B89A` | 次级强调、图表辅助色、登录页装饰 |
| `--accent-soft` | `#F0EEFF` | `#E8FAF5` | 次级浅色背景 |
| `--sidebar` | `#171A2B` | `#0E3A4A` | 侧栏背景 |
| `--sidebar-active` | `#5B5DE4` | `#159FD0` | 侧栏当前项 |

成功、警告、危险色继续使用独立语义变量，不因主题切换而失去可读性。暗色模式沿用同一色系，但会提高文字对比度、降低大面积亮色饱和度，并保持主题主色可识别。

### 3. 主题切换入口

在系统设置中新增“主题色系”设置项，提供两个选项：

- 蓝紫品牌
- 天蓝青绿

顶栏增加轻量主题切换入口，用于快速切换；设置页中的选择与顶栏操作保持双向同步。主题色系使用 `localStorage` 保存，键名为 `workbench_accent_theme`，默认值为 `indigo`。主题切换不影响浅色 / 暗黑模式的独立设置。

实现上，根节点使用 `data-accent-theme="indigo"` 或 `data-accent-theme="ocean"`；CSS 通过属性选择器覆盖主题变量，避免在每个页面中维护重复样式。Pinia 应用状态负责读取、写入和切换主题色系。

### 4. 登录页

- 保留现有品牌文案和登录流程。
- 登录页背景、主标题强调色、品牌标记、输入框聚焦态和主按钮使用当前主题色系。
- 蓝紫主题保留原有品牌气质，但弱化过重的暗色玻璃效果。
- 天蓝青绿主题使用浅冰蓝到白色的明亮背景，右侧登录区域保持干净、聚焦。
- 登录页允许在不登录的情况下切换主题，切换结果与登录后保持一致。
- 移动端保持单列布局，隐藏非必要装饰，确保表单和按钮可用。

### 5. 登录后页面

- 统一调整侧栏、顶栏、页面标题、面板、按钮、输入框、表格、标签、弹窗和空状态的颜色引用。
- 保持现有页面布局：总览、记录、计划、提醒、Todo、链接、工具箱、记账、备忘录、个人中心、系统设置均不改变业务结构。
- 统计卡片使用主题色作为第一强调色，收入 / 成功继续使用青绿，危险 / 支出继续使用珊瑚红，避免财务语义被主题色覆盖。
- ECharts 图表从 CSS 变量读取主色、辅助色、网格线和文字色；切换主题后重新渲染或更新图表。
- 交互状态需要同时覆盖 hover、focus、active、disabled 和 selected，保证主题切换不是只改变按钮颜色。

## 技术边界

- 修改范围集中在 `frontend/src/styles.css`、`frontend/src/stores/index.js`、`frontend/src/layouts/AppLayout.vue`、`frontend/src/pages/Login.vue`、`frontend/src/pages/Settings.vue`、`frontend/src/pages/Dashboard.vue` 和必要的共享组件。
- 不修改后端、接口请求、数据模型、路由守卫和业务操作。
- 不新增运行时依赖；使用现有 Vue、Pinia、Element Plus 和 ECharts。
- 主题状态必须在应用启动时先从 `localStorage` 恢复，再挂载根应用，避免页面闪烁到错误主题。

## 验证标准

1. 首次打开应用默认显示蓝紫品牌主题。
2. 从登录页切换到天蓝青绿后，登录页所有主要强调色立即更新；登录成功后仍保持天蓝青绿。
3. 在系统设置中切换主题色系，顶栏入口和当前页面立即同步，刷新后选择仍然保留。
4. 蓝紫和天蓝青绿两套主题在浅色、暗黑模式下均能正常显示，文字和控件保持足够对比度。
5. Dashboard 的折线图、饼图、柱状图在切换主题后与当前主题色同步，不残留旧颜色。
6. 移动端和桌面端布局无横向溢出，登录表单、导航、设置控件仍可操作。
7. `npm --prefix frontend run build:desktop` 成功完成。
